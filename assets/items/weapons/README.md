# Иконки оружия

- `sources/` — побайтовые копии исходных листов; оригиналы на Desktop не изменены.
- `icons/` — 28 игровых PNG: семь семейств × четыре редкости, RGBA, 64×64.
- `sheets.json` — проверенные координаты внешних рамок и SHA-256 исходников.
- `preview.png` — обзор для проверки, увеличение строго nearest-neighbor.

Порядок областей в `boxes`: COMMON (слева сверху), RARE (справа сверху),
EPIC (слева снизу), LEGENDARY (справа снизу). Координаты `[left, top, right, bottom]`
в пикселях исходника; правый и нижний края не включаются, как в Pillow crop.
Области подобраны по фактическим рамкам, с учётом различающихся отступов каждого
листа; деление ровно пополам для обрезки не используется. При замене исходника
утилита остановится до повторной проверки координат и обновления SHA-256.

Файлы `stuff.PNG` и `stuff_2h.PNG` соответствуют существующим ID `staff` и
`staff_2h`. Названия исходных файлов сохранены; игровые PNG используют ID проекта.
Цвета рамок сохранены из картинок, включая золотую LEGENDARY: цвета консольного
enum не используются для перекрашивания изображений.

## Повторная обработка

Для сборки нужен Pillow: `python -m pip install -r tools/requirements-assets.txt`.
Игра и функция поиска пути не требуют Pillow.

Из корня проекта:

```sh
python -B tools/build_weapon_icons.py axe --preview
python -B tools/build_weapon_icons.py --preview
```

Единый размер задан в `weapon_icons.ICON_SIZE`. Для смены стандарта измените
эту константу и пересоберите иконки. Для отдельной проверки другого размера:

```sh
python -B tools/build_weapon_icons.py --size 48 --output-dir assets/items/weapons/preview-48/icons
```

Обрезка сохраняет рамку. Масштабирование — только NEAREST, без фильтров или
сглаживания. Пропорции сохраняются с округлением размеров до целого пикселя;
остаток квадратного холста прозрачен. При 64×64 это может дать полосу в один
пиксель у слегка прямоугольного исходника. Содержимое и палитра не редактируются.

## Использование в будущем GUI

```python
from weapon_icons import weapon_icon_path
from rarity import Rarity

path = weapon_icon_path("axe", Rarity.EPIC)
path = weapon_icon_path(player.main_hand)
```

Возвращается абсолютный `Path`, независимый от рабочей папки, или `None`, если
подходящего изображения нет. Принимаются ключи WEAPONS, существующие алиасы ITEMS
и экземпляры оружия. `Weapon.icon_id` — только ссылка на семейство изображения;
она копируется существующей фабрикой и deepcopy, а редкость читается при запросе.
Стартовый «Простой меч» использует семейство `sword`. Новые неизвестные предметы
не получают случайную картинку. Боевые параметры и правила генерации не меняются.

GUI-инвентарь и загрузка изображений в виджеты в эту задачу не входят.

Проверка: `python -B -m unittest test_weapon_icons`.
